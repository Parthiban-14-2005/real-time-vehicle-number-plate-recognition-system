## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/user/real-time-vehicle-number-plate-recognition-system.git
cd real-time-vehicle-number-plate-recognition-system
pip install -r requirements.txt
python main.py
```
